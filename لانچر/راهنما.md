# اجرای سیستم با یک کلیک

روی «اجرا.vbs» دبل‌کلیک کنید. اگر فایل VBS در ویندوز غیرفعال است، «Start.cmd» را اجرا کنید.

لانچر:
- محیط پروژه و پیش‌نیازهای موجود را بررسی می‌کند.
- در صورت نیاز مایگریشن‌های دیتابیس را اجرا می‌کند.
- بک‌اند Django روی پورت ۸۰۰۰ و فرانت‌اند Vite روی پورت ۵۱۷۳ را در پس‌زمینه اجرا می‌کند.
- منتظر پاسخ‌دادن هر دو سرور و اتصال API می‌ماند.
- صفحهٔ ورود را در مرورگر پیش‌فرض باز می‌کند: http://localhost:5173/login
- سرور سازگار را دوباره استفاده می‌کند؛ اگر backend قدیمی همین پروژه پورت ۸۰۰۰ را گرفته باشد، فقط همان فرایند را جایگزین می‌کند. فرایندهای نامرتبط را خودکار متوقف نمی‌کند و دربارهٔ آن‌ها پیام روشن می‌دهد.
- سلامت فرانت‌اند را با بارگذاری صفحه، ماژول اصلی و صفحهٔ نمایندگی بررسی می‌کند؛ سلامت API نیز از endpoint عمومی و مسیرهای کلیدی (نمایندگی، مفاد تومان، داشبورد فضای کاری و طلبکاران) تأیید می‌شود تا سرور قدیمی که این مسیرها را ندارد بازاستفاده نشود.
- ورود از لینک لانچر، نام کاربری ذخیره‌شدهٔ ورود قبلی را پاک می‌کند تا صفحهٔ لاگین نمایش داده شود. اطلاعات مالی حذف نمی‌شوند.

این فولدر باید داخل ریشهٔ همین پروژه و کنار frontend و MyFullStackApp بماند. هنگام اجرا اینترنت لازم نیست؛ Node.js، محیط Python و وابستگی‌های نصب‌شدهٔ فعلی پروژه لازم هستند.

خطاهای راه‌اندازی در پوشهٔ logs ذخیره می‌شوند. در صورت خطا پیام آن نمایش داده می‌شود. بستن تب مرورگر سرورها را متوقف نمی‌کند.
